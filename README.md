# 站起來才算數：功能性訓練影片互動課

一支功能性訓練衛教動畫（16:9，2 分 32 秒）切成 7 段，搭配「影片教學法」互動網頁：每段看完就作答，最後做「30 秒坐站測試」、訂一張自己的練習卡。

**線上上課：** https://mattsue1003.github.io/functional-training-lesson/

**YouTube 完整影片：** https://youtu.be/ZqhLCazpOps

## 三個重點

1. **防跌，站著練**：跌倒大多發生在走路、站著、坐下時；扶穩固椅背練墊腳尖、原地踏步、前後腳站。
2. **轉位，練坐到站**：椅子、馬桶、汽車、沙發都是同一個動作；腳往後收、身體前傾、鼻子過腳尖、站起來。
3. **撿東西，也是訓練**：一手扶穩、屁股往後推、膝蓋彎、伸手往下拿；從椅子上 → 小板凳 → 地板。

另外說明：坐著抬膝、伸膝是很好的肌力基礎，但不等於功能性訓練；長照「復能」就是把功能性訓練帶進生活（1966 長照專線）。

## 課程流程

1. 課前猜一猜（8 題是非）＋ 3 個看片任務
2. 分段看影片：7 段、15 題互動（選擇、分類、「這樣練，可以嗎？」、填空、排序），答錯可回看；可開啟講師帶領提示
3. 課後再測：電影法投票＋同樣 8 題，顯示進步
4. 四大提問：翻卡複習、30 秒坐站測試（CDC STEADI 參考值）、承諾牆與練習卡、資源（復能、1966、安全檢查）

作答進度只存在學員自己的瀏覽器。
